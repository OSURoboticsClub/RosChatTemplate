# RFCs

Proposals and decision records for this project. Each RFC starts as a
proposal and becomes the record of what the team decided.

## Adding one

1. Copy `template.md` to a new file named `YYYY-MM-DD-short-title.md`.
2. Fill it in, leave Status as "Proposed", and open a pull request for review.
3. Once the team decides, update Status, Decision Date, and Deciders.

Don't rewrite a decided RFC. Write a new one and link it under "Superseded By".
