# RosChat Template

## Introcution

This project is intended to provide new users of ROS a useful learning experience. A template for the main UI can be found in ``roschat_app/roschat_main.py``.


## Project Requirements

Here are the requirements of the project:
 - Implement the ability to send and recieve message to and from all users
 - Users must be able to have a user name
 - Users should be able to send direct messages to other users

Some optional additional features to consider:
 - Verify user names are unique
 - Track and display the number of active users on the system
 - Log all sent messages

 You are welcome to implement any other additional features you think would be interesting. You might consider creating an additional dedicated server node to achieve some of these requirements.
